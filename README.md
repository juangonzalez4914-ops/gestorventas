sobre el proyecto

este es un proyecto realizado en c# y .net para crear un pequeño sistema de ventas e inventario

la idea es poder registrar productos, consultar el inventario y realizar ventas de una manera sencilla desde la consola.

que puede hacer?

el programa permite

registrar productos
consultar el inventario
registrar ventas
aplicar un descuento del 10%
calcular el iva del 19%
actualizar el stock despues de una venta
mostrar una alerta cuando queda poco stock
ver un reporte de las ventas
como ejecutarlo?

para ejecutar el proyecto se necesita tener instalado .net sdk.

primero se debe descargar o clonar el repositorio.

despues entrar a la carpeta del proyecto

y ejecutar el siguiente comando:

dotnet run

despues aparecera el menu del sistema en la consola.
